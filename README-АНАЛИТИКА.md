# Аналитический модуль «Фаворит» (курсовая работа)

Полноценная замена макета: сайт целиком посвящён аналитике эффективности
предприятия — витрина, статьи, отзывы и партнёры убраны, все разделы питают дашборд с базой данных, формами ввода, расчётом показателей, графиками,
отчётами и журналом действий.

## Состав

| Файл | Назначение |
|---|---|
| `analytics.php` | Дашборд: 4 KPI, сводный график, карточки разделов |
| `production.php` | Производственная аналитика: выпуск, брак, загрузка, форма ввода |
| `finance.php` | Финансовая аналитика: выручка, себестоимость, прибыль, рентабельность |
| `sales.php` | Продажи и маркетинг: заказы, средний чек, каналы, форма продажи |
| `hr.php` | Кадровая аналитика: численность, ФОТ, отделы, приём/увольнение |
| `reports.php` | Сводный отчёт, плановые показатели, экспорт CSV, журнал действий |
| `analytics_lib.php` | Метрики, SVG-графики, CSRF, сессии, аудит |
| `analytics_schema.php` | Схема БД и демонстрационные данные (6 месяцев) |
| `db.php` | Подключение: MySQL (OpenServer) → автоматический резерв SQLite |
| `config.php` | Параметры подключения к MySQL (host, port, база, логин, пароль) |
| `install.php` | Установка базы данных в один клик: создаёт favorit_db и импортирует дамп |
| `database/favorit_db.sql` | Полный дамп базы: 11 таблиц и демонстрационные данные |
| `analytics.css` | Оформление аналитического контура (светлые карточки, тёмное меню) |

## Запуск

1. Открыть проект в OpenServer (домен на папку `favorit`), MySQL 8.
2. Открыть `install.php` и нажать «Установить базу данных» — создаётся база
   `favorit_db`, выполняются `database/favorit_db.sql` и демо-данные.
   При первом заходе на `analytics.php` таблицы тоже создаются автоматически.
3. Если MySQL недоступен, система сама переходит на SQLite (`data/favorit.sqlite`
   или каталог из переменной `FAVORIT_DATA_DIR`).
4. Вход: `manager` / `manager123` (создаётся автоматически только для пустой таблицы
   пользователей). На действующем сайте используются существующие учётные записи.

## Что умеет

- Ввод выпуска, брака, часов и себестоимости по цехам за месяц.
- Ввод продаж по каналам (заказы, выручка).
- Расчёт производительности, брака, загрузки мощностей, выручки, прибыли,
  рентабельности, среднего чека и сравнение с предыдущим месяцем.
- Графики на SVG без внешних библиотек; адаптивная вёрстка.
- Экспорт сводного отчёта в CSV (UTF-8 BOM, `;`) — открывается в Excel.
- Журнал действий пользователей и плановые показатели.
- Защита: подготовленные выражения PDO, CSRF, валидация, PRG, экранирование вывода.

## Демо-данные

Май–октябрь 2025: выпуск 10 500 → 12 480 изделий, выручка 7,9 → 8,54 млн ₽,
брак 2,4 %, загрузка 87 % — как на образце-видео.


## Демо и защита

- Данные создаются автоматически при первом запуске (май–октябрь 2025).
- Сброс демо: раздел «Данные» → «Пересоздать демо-данные».
- Полный сценарий показа и ответы на вопросы — в файле ЗАЩИТА-КУРСОВОЙ.md.
