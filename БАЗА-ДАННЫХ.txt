БАЗА ДАННЫХ: КАК ПОДКЛЮЧИТЬ И КАК ОНА РАБОТАЕТ
=================================================

Система «Аналитика эффективности предприятия» работает с реляционной базой
данных favorit_db. Поддерживаются два режима:

  1) MySQL / MariaDB из OpenServer — основной режим (как в методичке);
  2) SQLite — резервный файл, включается автоматически, если MySQL не запущен.

Ничего настраивать вручную не нужно: при первом открытии сайта база создаётся
сама. Ниже — что происходит и как проверить.


1. САМЫЙ БЫСТРЫЙ ЗАПУСК (OpenServer)
-------------------------------------------------
  1. Скопируйте папку проекта в OpenServer\domains\ (например, domains\favorit).
  2. Запустите OpenServer, дождитесь зелёного индикатора MySQL.
  3. Откройте в браузере:  http://favorit/install.php
     Нажмите «Установить базу данных» — появится отчёт по таблицам.
  4. Откройте http://favorit/analytics.php
  5. Вход: manager / manager123 (администратор).

  install.php создаёт базу favorit_db, выполняет database/favorit_db.sql
  и показывает, сколько записей в каждой таблице.

2. ФАЙЛЫ, ОТВЕЧАЮЩИЕ ЗА БАЗУ
-------------------------------------------------
  config.php                — хост, порт, имя базы, логин и пароль MySQL
  db.php                    — подключение, автозапуск установки, резерв SQLite
  analytics_schema.php      — структура таблиц и демонстрационные данные
  database/favorit_db.sql   — полный дамп базы (структура + данные),
                              его можно импортировать в phpMyAdmin вручную
  install.php               — установка базы «в один клик» через браузер

3. ПАРАМЕТРЫ ПОДКЛЮЧЕНИЯ
-------------------------------------------------
  По умолчанию в config.php:

      'host'     => '127.0.0.1',
      'port'     => '3306',
      'database' => 'favorit_db',
      'user'     => 'root',
      'pass'     => '',

  Если в OpenServer MySQL слушает другой порт (например, 3307) — поменяйте
  'port'. Если задан пароль root — впишите его в 'pass'.
  Альтернатива: переменные окружения DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASS.

4. ГДЕ СМОТРЕТЬ БАЗУ
-------------------------------------------------
  OpenServer → меню «Дополнительно» → phpMyAdmin
  (или http://localhost/phpmyadmin) → база favorit_db → 11 таблиц:

      users          — пользователи и роли (администратор / сотрудник)
      an_categories  — категории продукции
      an_products    — справочник продукции и цены
      an_channels    — каналы продаж, план и затраты
      an_production  — выпуск, брак, часы и себестоимость по цехам
      an_sales       — продажи по каналам за месяц
      an_orders      — портфель заказов и статусы
      an_defects     — брак по причинам и потери
      an_staff       — штат сотрудников и оклады
      an_targets     — плановые и допустимые показатели
      an_audit       — журнал действий пользователей

  Связи: an_products.category_id → an_categories.id (внешний ключ).
  В остальных таблицах связь по названиям цехов и каналов — как в демо-данных.

5. ИМПОРТ ДАМПА ВРУЧНУЮ (phpMyAdmin)
-------------------------------------------------
  1. phpMyAdmin → вкладка «Импорт».
  2. Файл: database/favorit_db.sql, кодировка utf-8.
  3. «Вперёд». Скрипт сам создаст базу favorit_db и все таблицы.
  4. Проверка: SELECT COUNT(*) FROM an_production;  -- 18

  Из консоли:  mysql -u root < database/favorit_db.sql

6. ЧТО ПРОИСХОДИТ ПРИ ПЕРВОМ ЗАПУСКЕ
-------------------------------------------------
  db.php:
   1) читает config.php;
   2) подключается к MySQL; если базы нет — выполняет CREATE DATABASE;
   3) если таблицы an_production ещё нет — импортирует database/favorit_db.sql;
   4) если MySQL недоступен — создаёт файл data/favorit.sqlite и работает с ним;
   5) analytics_schema.php дополняет структуру и создаёт демо-данные
      только в пустой базе (существующие записи не перезаписываются);
   6) если таблица users пуста — добавляет администратора manager / manager123.

7. ПРОВЕРКА, ЧТО БАЗА РАБОТАЕТ
-------------------------------------------------
  - Откройте раздел «Данные» (admin.php): там показаны движок (MySQL или
    SQLite), имя базы, количество таблиц и записей, список пользователей.
  - Добавьте запись в разделе «Производство» — цифры на дашборде изменятся.
  - Кнопка «Скачать бэкап SQL» выгружает все таблицы в виде SQL-файла.
  - Кнопка «Пересоздать демо-данные» возвращает исходные цифры:
    12 480 изделий, 8 540 000 ₽, брак 2,4 %, загрузка 87 %.

8. ЕСЛИ ЧТО-ТО НЕ ПОДКЛЮЧАЕТСЯ
-------------------------------------------------
  «could not find driver»
      В OpenServer включите расширения pdo_mysql и pdo_sqlite:
      правый клик по флажку → «Настройки» → «PHP» → расширения.

  «Access denied for user 'root'»
      В config.php укажите пароль root, который задан в OpenServer.

  «Unknown database 'favorit_db'»
      Откройте install.php и нажмите кнопку установки — база создастся.

  Сайт работает, но в разделе «Данные» написано «SQLite (резерв)»
      MySQL не запущен. Запустите его в OpenServer и обновите страницу —
      система снова подключится к MySQL.
